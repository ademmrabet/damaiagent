\chapter{Lessons Learned and Limitations}
\label{ch:lessons-learned-and-limitations}
\section{Technical lessons}
\begin{itemize}
\item \textbf{PDF layout parsing is a geometry problem wearing a text-processing costume.} Nearly every hard bug in Sections 6–7 was, underneath, a question about character position and size that a text regex could only ever approximate — and every regex-only attempt at these problems eventually hit a real counter-example that only geometry could resolve correctly.
\item \textbf{A single source of truth prevents entire classes of self-inflicted bugs.} Several fixes were only necessary because two different parts of the code implemented equivalent logic slightly differently (e.g. one action-code normalization step existing in two places, one of which was missed when the other was updated) — consolidating to one shared function, referenced from everywhere, was consistently the more durable fix.
\item \textbf{Whole-document validation catches what sampling misses.} Bugs affecting 1–2\% of activities were repeatedly invisible on a single sample page and only surfaced by checking every one of the 79 pages, or all 327 built nodes, at once.
\item \textbf{Restricting an LLM's role to verified rephrasing, rather than open-ended reasoning, is what makes an LLM usable at all in a compliance-sensitive context.} The grounding check (Section 8.4) is, in the author's assessment, the single most important architectural decision in the project — every later feature (multi-language, mandatory notes, tone) was designed to extend the system's capabilities without ever weakening that one guarantee.
\end{itemize}
\section{Known limitations}
\begin{itemize}
\item Two hierarchy-4 (\texttt{threshold\_\allowbreak{}variant}) parsing gaps remain unresolved by design: fused level-and-footnote superscript digits that pdfplumber tokenizes inconsistently, and plain space-separated amounts inside titles (as opposed to comma-formatted ones), both flagged as needing true geometry-based digit detection rather than another text-pattern patch.
\item Two garbled role-name titles (2 of 327 nodes) remain, after one candidate fix was tried, found ineffective, found to cause a regression, and reverted; the true, mid-run character-shrinking root cause is understood but not yet fixed.
\item The action-geometry extractor's per-task action counts disagree with the trusted text-based counts on approximately 14\% of activities; the text-based count is used as ground truth throughout the rest of the system, and this gap is accepted rather than chased further within the project's time budget.
\item Text search is lexical, not semantic; a question phrased with entirely different vocabulary from the actual activity title will score lower than a closer phrase match, regardless of whether the underlying meaning matches.
\item Vague-question and out-of-scope detection are heuristic, not a true topic classifier, and a small number of edge cases are known to be misclassified — though never in a way that produces a fabricated DAM answer.
\item Several LLM-dependent features (the Groq model migration, the grounding-fallback-frequency fix, tone detection) could not be independently verified against a live call to the Groq API from within the development sandbox, due to a persistent outbound network restriction, and instead rest on mocked-provider testing plus the intern's own live verification outside the sandbox.
\item The five-language interface translations were produced by the AI collaborator itself and have not yet been reviewed by a native speaker of French, Spanish, Portuguese, or Arabic — acceptable for a first release of interface labels, but flagged explicitly for review before any formal multilingual demonstration. The underlying DAM facts themselves are unaffected by this, since they remain subject to the same English-language grounding check regardless of display language.
\item Render's free hosting tier sleeps after 15 minutes of inactivity, producing a 30–60 second cold-start delay on the first request after idle — a known and accepted trade-off of using a free hosting tier for a project of this scope.
\end{itemize}
