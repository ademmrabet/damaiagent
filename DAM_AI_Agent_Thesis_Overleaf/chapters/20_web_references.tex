\markboth{Web References}{Web References}

\noindent All sources cited in this thesis are freely accessible online; they are listed together below as web references rather than split into a separate print bibliography, since no source used required access beyond a public URL.

\begin{enumerate}[leftmargin=1.4cm,itemsep=8pt]
  \item Chapman, P., Clinton, J., Kerber, R., Khabaza, T., Reinartz, T., Shearer, C., \& Wirth, R. (2000). \textit{CRISP-DM 1.0: Step-by-Step Data Mining Guide}. SPSS Inc. -- the methodology framework structuring this thesis.
  \item African Development Bank Group. \textit{Delegation of Authority Matrix} (internal reference document, ``updated dam file.pdf'', 79 pages). The project's source data; an internal Bank document, not publicly published, referenced here only for the intern's own project documentation.
  \item pdfplumber documentation. \textit{jsvine/pdfplumber} -- PDF text, character, and table extraction library. \url{https://github.com/jsvine/pdfplumber}
  \item scikit-learn documentation. \textit{TfidfVectorizer} and cosine-similarity utilities. \url{https://scikit-learn.org/stable/modules/generated/sklearn.feature_extraction.text.TfidfVectorizer.html}
  \item NetworkX documentation. \textit{MultiDiGraph -- Directed graphs with self loops and parallel edges}. \url{https://networkx.org/documentation/stable/reference/classes/multidigraph.html}
  \item FastAPI documentation. \url{https://fastapi.tiangolo.com}
  \item React documentation. \url{https://react.dev}
  \item Vite documentation. \url{https://vitejs.dev}
  \item GSAP (GreenSock Animation Platform) documentation. \url{https://gsap.com/docs/v3/}
  \item Groq Inc. \textit{GroqCloud Developer Documentation} -- Rate Limits and Model Deprecations pages, consulted directly (not from training knowledge) to confirm current free-tier model availability. \url{https://console.groq.com/docs/rate-limits} and \url{https://console.groq.com/docs/deprecations}
  \item Ollama documentation. \textit{Local large language model runtime}. \url{https://ollama.com}
  \item Docker documentation. \textit{Dockerfile reference} and \textit{Compose file reference}. \url{https://docs.docker.com}
  \item Render documentation. \textit{Free instance types} and \textit{Deploying a Docker web service}. \url{https://render.com/docs}
  \item Python \texttt{difflib} module documentation (standard library) -- used for deterministic typo-tolerance matching. \url{https://docs.python.org/3/library/difflib.html}
  \item Pydantic documentation. \textit{Data validation using Python type hints}, used for the project's typed schema layer. \url{https://docs.pydantic.dev}
\end{enumerate}
